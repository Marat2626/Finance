# Smart Finance AI
Умное приложение для анализа расходов с AI-помощником для экономии финансов и управлением финансовой грамотности.
## Возможности

### **Полный финансовый обзор**
- Агрегация транзакций со **всех банков** в одном месте
- Визуализация расходов в виде **круговых диаграмм и графиков**
- Достижение поставленных накоплений

### 🤖 **AI-финансовый помощник**
- **Анализ** ваших доходов и расходов с помощью нейросети
- **Персонализированные советы** по экономии
- **Рекомендации** по распределению бюджета

### 💡 **Инструменты для экономии**
- Сравнение расходов по месяцам
- Выявление "финансовых дыр" (куда уходят деньги)
- Планирование финансовых целей


### 💡 **Инструменты для экономии**
- Сравнение расходов по месяцам
- Выявление "финансовых дыр" (куда уходят деньги)
- Планирование финансовых целей
- Категоризация всех транзакций
- Отслеживание прогресса накоплений
